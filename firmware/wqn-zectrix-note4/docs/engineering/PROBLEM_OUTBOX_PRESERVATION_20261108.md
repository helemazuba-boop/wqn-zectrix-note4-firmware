# R-09：Problem 坏行重写前保全原文

Problem outbox 继续允许读取健康的换行记录，并区分 malformed、暂时不可解析与
opaque 身份。现在 Commit、ACK、quarantine 的有损重写必须先保全完整源文件。
不能把坏行或未换行尾部当作可恢复的有效学习事实，也不能因为 cJSON 分配失败删除它们。

## 保全流程

`ReadOutboxLines` 为存储 owner 生成本次读取证明：存在性、原始字节数、SDK CRC、
需修复标记及被舍弃的物理帧数。普通查询不计算无用的 CRC。物理帧数包括空行和
未完成尾部，不表示丢失了同样数量的有效学习记录。

重写函数必须接收该证明。坏行存在时，先把整个 `po_outbox.jsonl` 复制到新的排他
暂存文件，校验读取证明，完成 flush、fsync、close，再与当前源逐字节比较，最后
由唯一存储 owner 发布保全副本。正常 journal 的临时文件同步完成后、轮转主文件前，
还必须重新逐字节比较源与保全副本。保全或复验失败不轮转/覆盖当前主文件；
之后的正常发布故障仍遵循既有 `.bak` 恢复协议，独立保全副本继续保留。

CRC 只用于检测 owner 事务内的源漂移，不是身份认证或密码学授权。逐字节比较和
关闭错误检查同时保留。SPIFFS 没有符号链接；主机测试另外拒绝保全槽位的链接和 FIFO。
所有这些操作都在存储 owner 内执行，不允许另一任务并发创建同路径的文件。

## 有界留存

| 对象 | 规则 |
| --- | --- |
| `po_outbox.jsonl.raw0` 至 `.raw3` | 最多 4 个原文槽位，每个源文件最多 128 KiB |
| 对应的 `.raw0.tmp` 至 `.raw3.tmp` | 未完成或持久性不明确的暂存副本，占用该槽位，保留原样 |
| 已有 committed 副本 | 仅在大小、读取证明与全部字节均匹配时复用，不能只比大小 |
| 不同或未知的旧副本 | 不覆盖、不轮换清除，也不自动转成学习记录 |
| 无可用槽位、超限、I/O/同步/复验错误 | 保留主文件并返回错误，日志说明需先导出原文 |

健康的追加和 ACK 不消耗槽位。幂等但没有重写的请求也不制造保全文件。
本实现新生成的副本最多占用约 512 KiB；未知已有文件不因此获得删除许可。
128 KiB 也约束 journal 读取，覆盖 200 条上限内的合法最大长度记录，防止无限坏字节扫描。
字节上限不是磁盘 I/O 的物理最坏耗时保证。

崩溃后，已同步但未发布的 `.tmp` 不自动提升或删除；新的修复尝试使用另一个空槽位。
已发布且完全匹配的原文可以在正常 `.bak` 恢复后复用。保全文件不是启动恢复候选，
不会被 Peek、ACK 或上传逻辑解析，也不触发自动清理。

## 导出与兼容

逻辑证据通道按精确文件名列出 Problem 的 primary/tmp/bak、rejected、parked 与
8 个保全/暂存文件，连同真实缺失状态一起发送。接收器逐字节保存并独立复验。
不扩大成任意 `po_` 前缀搜索；同前缀的无关文件不会导出。

旧 WQE1 导出不含 Problem 文件组，新接收器仍可按原有 manifest 复验它们，不替它们
补造 Problem 缺失结论。新 Problem 文件组一旦出现，必须完整列出全部 13 个名字；
已冻结的旧工具包保持原样，新的设备导出需配套本批工具。手动开机保全的全 Flash
通道同样保留这些原文字节，离线 SPIFFS reader 可提取它们；不赋予安装或维修授权。

## 验证与验收边界

`test_problem_outbox_recovery.py` 使用实际 SDK cJSON/CRC、生产事务与真实 libc 临时文件。
覆盖追加/ACK/quarantine、二进制坏行、CRLF、超长行、未换行尾部、同大小不同副本、
槽位耗尽、读取/写入/flush/fsync/close/rename 错误、源漂移、发布前篡改、排他创建、
精确大小边界，以及两个实际子进程退出点。`--evidence-only` 只运行保全专项。

六种保全语义变异和 Problem 导出遗漏变异都必须完成场景并触发目标断言。
编译错误、异常、崩溃及超时不算检测成功。统一门禁清单扩展到 160 项；清单不是
本次执行结果，具体提交、构建、完整新跑与未执行项由本轮证据报告记录。

这一批改变设备运行时，旧 `val-20261107.5` 不包含它。需要新候选版本、配套工具、
SPIFFS 容量压力/掉电/USB 导出 HIL 和独立验收；主机的 fork/exit 不能代替物理断电。
R-08 的真实身份/认证、安装/回滚与 R-09 的实机验收仍未关闭。
