## Todo 绘制基线

- 缓存仅由 EPD owner 访问，只由成功的完整 Todo 绘制建立。
- 正文签名包含日期、列表/选择窗口、同步和完成状态、任务内容、导航状态，以及根据当前时间计算的逐项逾期状态。跨日、刚逾期、选中项或内容变化均完整构图，不仅刷新时钟。
- 只有 `kClock`、屏幕仍是 Todo、黑白镜像可信且正文签名相同，才保留正文并重绘状态栏。`kSelection` 继续走原有完整构图和刷新策略。
- 绘制失败使缓存失效；尝试绘制任何其他页面之前也使缓存失效，因为失败的页面可能已改动当前绘图缓冲区，却没有推进 `g_last_rendered_screen`。
- 该优化节省列表字体绘制/构图。实际面板刷新范围仍由显示服务的 dirty rect 和既有保护决定，不承诺波形耗时或功耗下降比例。
