# 单词 UI：对齐主页的书页风格

2026-10-18，`feat/ui-rewrite`。依据 `doc/note4_word_home_style.html` 修订版实施：单词页没有完整阅读功能，本次不新增阅读态、正文翻页或长按上键入口。

## 实现

- 单词入口、学习卡片正反面、准备 / 不可用状态、复习完成 / 无到期状态统一使用原生字体、16px 内容边距、开放分区、细线与主页式左侧焦点标记。
- 移除圆角卡片、释义与回忆提示外框、常驻底部操作说明。现有短按上下 / 确认及长按确认的学习语义保留，`HandleWordAppInput` 未修改。
- 主词使用原生 32px / 24px 字形；过长时最多两行并标明省略。英文优先按空白换行；释义、例句、译文根据剩余空间分配行数，溢出时显示省略号。没有展开或翻页暗示。
- 释义已有 `n.`、`v.`、`adj.` 等词性前缀时直接沿用释义；仅在缺少前缀时补充独立词性字段，避免预设词库显示为 `n n. 调查`。保留多词性释义与原始缓存数据，兼容大小写、前后空白及字段有无句点的差异。
- 复用已有 CJK 字库，新增独立 Noto Sans 1bpp 字模用于扩展拉丁字符、IPA、重音、长音与常用附加符号。16 / 20px Regular、24 / 32px Bold 各 1495 字形；既有 `ui_fonts.c` 未改动。
- 同一文本行按原生基线混排拉丁 / IPA 与 CJK。缺字使用可见替代字符，避免旧路径静默漏字；不进行运行时字号缩放。
- 今日统计明确标注“已复习 / 答对”。到期数量缓存以 -1 表示尚未取得；0 表示真实零值。遗忘数量未知也显示 `--`，不再借用整个词库数量。
- 启动自测会完成模拟复习并写入到期数 0；使用作用域保护恢复自测之前的缓存，避免启动后将未知数误显示为真实零值。自测在 SyncService 启动前运行。
- 快照只投影现有保存状态：暂存或提交失败显示失败原因；等待保存显示对应状态。准备失败等消息出现在入口内容区。界面没有将 RAM 接受等同于持久化成功。
- 刷新签名覆盖数量提示、词库 / 模式、保存反馈与状态栏图标，并给文本加长度前缀，防止云端文本中的分隔符碰撞。

本次仍通过现有 `RefreshFrame` / `RefreshRegion` / `RefreshStableRegion` 请求面板 owner 绘制，保留刷新调度；没有新增任务、网络请求、轮询、活动发布、唤醒源，也未改变睡眠、硬件时序或存储协议。
